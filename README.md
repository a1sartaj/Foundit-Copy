# Foundit Clone (React + Tailwind CSS)

A modern and responsive **Foundit Job Portal Clone** built using **React.js**, **Tailwind CSS**, and modern UI libraries.

This project recreates the main landing page of the Foundit website including:

* Responsive Navbar
* Hero Section
* Search Bar
* Profile Completion Section
* Job Cards
* Featured Companies Slider
* Footer Section
* Modern UI/UX

---

# 🚀 Tech Stack

* React.js
* Tailwind CSS
* Lucide React Icons
* React Icons
* Swiper.js
* Vite

# ⚙️ Installation

## 1. Clone Repository

```bash
git clone https://github.com/your-username/foundit-clone.git
```

---

## 2. Go To Project Folder

```bash
cd foundit-clone
```

---

## 3. Install Dependencies

```bash
npm install
```

---

## 4. Install Required Packages

### Lucide React

```bash
npm install lucide-react
```

### React Icons

```bash
npm install react-icons
```

### Swiper Slider

```bash
npm install swiper
```

---

# ▶️ Run Project

```bash
npm run dev
```
